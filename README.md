# Angular Task Manager

A small task management app built with Angular 18 as a hands-on project for learning Angular. Select a user to view their tasks, then add tasks associated with that user.

## What it demonstrates

- Standalone Angular components and component composition
- Parent-child communication with inputs and outputs
- Template control flow and event binding
- Forms with two-way data binding
- A service for managing task data

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm start
```

Open `http://localhost:4200/` in your browser. The app reloads when source files change.

## Available scripts

- `npm start` starts the development server.
- `npm run build` builds the app for production.
- `npm test` runs the unit tests.
